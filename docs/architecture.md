# 架构说明 / Architecture

本文件描述本实践在华为云上的目标架构、组件职责与数据流向，供部署与运维参考。

## 1. 总体架构

本实践以「凭据生命周期治理」为目标，采用无服务器架构：由函数工作流承载轮转逻辑，由定时触发器驱动每日执行，由消息通知服务完成主动触达，由对象存储服务托管部署包与模板。

```
[定时触发器 TIMER] --每天--> [轮转函数 rotate]
                              |
                              |-- 调用 --> [IAM] 创建/禁用/删除访问密钥
                              |-- 调用 --> [CSMS] 保存最新密钥明文（可选）
                              |-- 触发 --> [通知函数 notifier]
                                            |
                                            |-- 发布 --> [SMN 主题]
                                                           |
                                                           |-- 邮件 --> [订阅者]

[清单函数 inventory] --每天--> [IAM] 列举用户 --> [OBS] 写入用户清单
```

## 2. 组件职责

### 2.1 轮转函数 rotate

核心函数。入参为事件（来自定时触发器或手动触发），执行以下步骤：

1. 通过 IAM v3 列举目标用户及其访问密钥；
2. 对每把密钥，依据创建时间与阈值计算动作：
   - 年龄 ≥ `ROTATION_PERIOD_DAYS` → 创建新密钥；
   - 年龄 ≥ `INACTIVE_PERIOD_DAYS` → 禁用旧密钥；
   - 年龄 ≥ `DELETE_PERIOD_DAYS` → 删除旧密钥；
3. 新密钥明文通过通知函数披露；
4. 可选将最新密钥写入凭据管理服务。

### 2.2 清单函数 inventory

定期列举当前域下的 IAM 用户，输出用户清单到对象存储服务，供轮转范围确认与安全审计使用。

### 2.3 通知函数 notifier

接收轮转结果摘要，封装为邮件正文，发布到消息通知服务主题。邮件订阅者由此获知密钥变更动作与新密钥明文。

### 2.4 定时触发器 TIMER

函数工作流原生触发器，使用 Cron 表达式（`0 0 0 * * ?`）每天零点触发轮转函数。该触发器为定时类触发，与事件源解耦。

## 3. 凭据与权限模型

- 三个函数均绑定同一个**函数执行委托**（Identity Agency），运行时通过 `context` 注入临时凭证，无需在代码中硬编码；
- 委托需具备以下服务权限：**IAM 管理类角色**、**SMN 发布权限**、**OBS 读写权限**、**CSMS 读写权限**；
- 对象存储服务的桶策略需将委托主体（`domain/<domain_id>:agency/<agency_name>`）加入数据面读写允许列表。

## 4. 多账号场景

默认实现在当前账号域内列举用户。若需在多个账号间统一治理，可采用以下方式：

- 在目标域创建 IAM 委托，将本账号设为受信方；
- 轮转函数切换至目标域执行上下文，对该域用户进行密钥治理；
- 结合统一配置（如配置文件或环境变量）维护域清单，由清单函数逐域扫描。

该模式复用华为云 IAM 委托机制，无需额外的跨账号同步组件。

## 5. 容错与可观测

- 函数内部对每次云服务调用包裹异常捕获，失败时记录错误码与错误信息，便于定位；
- 轮转动作幂等：同一把密钥在同一生命周期阶段重复触发不会产生副作用；
- 建议为函数开启日志投递，结合云监控查看执行指标。

## 6. 部署包说明

- 每个函数独立打包为 zip，包含 `index.py` 与 `common/` 公共模块，以及 `huaweicloudsdk*` 依赖；
- 部署包上传到对象存储服务后，由 Terraform 引用 `code_url` 创建函数；
- 公共依赖需使用与目标运行时（Python 3.9 / Linux x86_64）一致的纯 Python 轮子打包。
